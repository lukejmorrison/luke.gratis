Maker of small tools for Omarchy

I run Omarchy every day. David Heinemeier Hansson made the system. I make the pieces I kept reaching for.

CanvasForge is a native screenshot annotation canvas for Arch, on the AUR. OmaWin puts Windows-style title bars on floating Hyprland windows, with a scratchpad to minimize into. I wanted a laptop my mom could recognize. OmaMusic plays YouTube Music through Quickshell and a local mpv. OmaNosey is the idle screensaver that is also a nosey QR honeypot.

The same desk has OmaRemote for RustDesk, TeamViewer, Tailscale, and VNC, OmaKeytron for a Keychron V6 Max, OmaSync for carrying a folder across a bad network, and OmaMount, an opinionated way to mount a NAS. There is a one-shot TeamViewer fix for Wayland, and a set of Quattro themes.

Away from the window manager: Chunder turns VigiAccess adverse-event dumps into something you can search. The name is British slang for spew, because nausea always charts. VoiceDNA is a try at recognizable AI voice fingerprinting. code2md turns source into Markdown so handing a codebase to an agent costs less. Tracker is the open tracker.

Truly helpful, truth-seeking, and fun

That is the line on X, and it is the brief. Be useful to a real person. Say the true thing. Have a good time doing it. I get bored of the same take copied across ten accounts.

I work with coding agents all day. The rule I want is ordinary. If a bot is about to do something privileged, it stops and asks, and I approve it with a fingerprint or a face. I built that for my own machines. Helping includes not letting the machine run off with the keys.
